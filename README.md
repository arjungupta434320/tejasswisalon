## 🚀 Getting Started

### 1-Click Launchers (Windows)
- Double-click **`START_WEBSITE.bat`** to run the local development server at `http://localhost:5173`.
- Double-click **`BUILD_PROJECT.bat`** to compile the production build into `dist/`.
- Double-click **`PREVIEW_PRODUCTION_BUILD.bat`** to preview the production build at `http://localhost:4173`.

### Manual CLI Commands
```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
